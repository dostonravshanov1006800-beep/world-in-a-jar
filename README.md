# Мир в банке / World in a Jar

HTML5-игра для **Яндекс Игр**. На столе у окна стоит стеклянная банка, внутри
парит крошечная живая планета. Ты влияешь на погоду и даёшь один совет в день
каждому жителю — они сами решают, послушаться или нет.

## Запуск

1. **Двойной клик по `index.html`** — игра работает локально (`file://`), офлайн.
2. Или `python -m http.server` в папке игры → http://localhost:8000.
3. `libs/three.min.js` уже включён (Three.js **r149**, UMD). Если нужно
   обновить: https://unpkg.com/three@0.149.0/build/three.min.js → положить
   как `libs/three.min.js`.
4. Без Yandex SDK игра автоматически работает в mock-режиме (реклама —
   заглушка на 1 секунду, язык из браузера, сохранения в localStorage).

## Как залить на Яндекс Игры

1. Заархивируйте **содержимое** папки (index.html должен быть в корне ZIP):
   `zip -r world-in-jar.zip . -x "*.DS_Store"` (на Windows: выделить все файлы → «Отправить» → «Сжатая ZIP-папка»).
2. В [консоли разработчика Яндекс Игр](https://games.yandex.ru/console/) создайте черновик игры.
3. Загрузите ZIP в раздел «Черновики» → «Загрузить архив».
4. Проверьте в модерации: модерируемая версия должна открываться без ошибок.
5. SDK подключается автоматически (`/sdk.js` на домене Яндекс Игр).

## Технологии

- Three.js r149 (UMD, без аддонов), чистый ES2018, без сборщиков и npm.
- Все текстуры/звуки/иконки процедурные (Canvas 2D, WebAudio, SVG).
- Без CDN, внешних шрифтов и картинок. Только локальные файлы + Yandex SDK.
- Тиры качества high/medium/low c автоопределением по FPS.
- Сохранения: localStorage + резервная копия; Yandex player.setData при наличии SDK.
- Языки: RU / UZ / EN, переключаются на лету.
- Отладка: добавьте `?debug=1` к URL (FPS, draw calls, seed, население).

## Управление

- Тяните банку пальцем/мышью — вращение (с инерцией).
- Щипок / колесо мыши — зум от «весь стол» до «макро жителя».
- Двойной тап — вернуть общий вид.
- Тап по жителю — карточка: нужды, характер, отношения, **один совет в день**.
- Внизу — колесо погоды (тратит «Энергию неба», она копится сама).
- Радуга доступна только после дождя + солнца.

## Что нового в v1.1

- Крышка банки стоит на горлышке (раньше висела рядом и выглядела «оторванной»)
- Резкость на телефонах: рендер в native DPR (до 2.75x), планета детальнее
  (icoSub 6-7), облака 1024x512
- Сцена ярче: тонмаппинг 1.18, солнце 2.3, подсветка и полусфера усилены
- Современные телефоны стартуют на тире high, слабые — medium; авто-тюнинг
  FPS снижает тир плавно
- Защита от гонки качества до построения мира (applyTier/applyShadowTier guards)
- Яндекс SDK грузится только на платформе Яндекса (нет лишних 404)

## Что нового в v1.2 — «4K-режим»

- Тир high рендерит в **нативном разрешении экрана** (до 4x DPR) — без даунскейла
- Тир medium поднят до 3x DPR, тени 1536
- Все процедурные текстуры перерисованы крупнее: дерево стола 1024px,
  нормал-карта 512px, бирка 4x плотность, царапины стекла 512px
- Анизотропная фильтрация (макс. уровень GPU) на дереве, бирке, облаках, стекле
- Авто-тюнинг FPS работает как раньше: слабые устройства плавно уходят на
  low-тир без «мыла» (1.5x)

## Что нового в v1.3 — чёткая земля

- **Попиксельная текстура планеты**: цвет теперь считается для каждого пикселя
  (1024x512, equirect), а не по вершинам — континенты, берега, пустыни и леса
  с попиксельной детализацией + микрозерно, «мыльные пятна» исчезли
- **Нормал-карта рельефа** из той же карты высот — горы и дюны освещаются
  попиксельно, а не только по крупным граням
- Двухфазная генерация: черновик 512px рисуется мгновенно, полная детализация
  догружается в фоне без фризов; при пересоздании мира фоновая задача отменяется
- Стол получил лак (clearcoat), в комнате появились дощатый пол и два стула
- Экран «Создаём мир…» на время генерации (ru/en/uz)
